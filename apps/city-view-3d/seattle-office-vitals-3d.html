Google Maps Platform key needed

Google's photorealistic 3D tiles stream directly from Google and require your own API key. The key is kept in this browser's local storage and is sent only to tile.googleapis.com. Nothing here goes anywhere else.

  1. In Google Cloud Console, create or pick a project and enable the Map Tiles API.
  2. Create an API key. Restrict it to the Map Tiles API. If you serve this page from localhost, add an HTTP-referrer restriction for it too.
  3. Paste it below. You can also open this file with ?key=YOUR_KEY in the address bar.
